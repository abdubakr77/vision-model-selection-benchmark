# Project brief (summary)

**Objective:** a practical benchmark to decide when a company should use traditional computer vision, YOLO, Vision Transformers, multimodal/VLM models, cloud vision models, or private/local models, across realistic enterprise scenarios.

**Scenarios:** manufacturing defect detection, document / image understanding, retail / product recognition.

**Model families:** YOLO / detection, Vision Transformer, open-source VLM, Gemma-family multimodal model (where applicable), cloud-hosted vision model, local/private model.

**Measured:** task quality, latency, GPU memory, model size, false positives, false negatives, cost per 1,000 images, explainability.

**Deliverables:** see CHECKLIST.md.

**Outcome:** a reusable R&D, sales and client-advisory asset that can be extended with more models and use cases.
